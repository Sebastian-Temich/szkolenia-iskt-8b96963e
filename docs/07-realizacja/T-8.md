## Decyzje

- Dowód W-03/K1–K3 („wynik zapytań w raporcie”) → test pgTAP `supabase/tests/dane_startowe.test.sql`
  (plik spoza „Zakresu”). `shctl db` nie ma komendy SQL, a `psql`/`supabase` są w sandboxie
  zabronione; tak samo jak w T-7 jedyną drogą zapytań na bazie lokalnej jest `shctl db test`. Test
  zostaje w repo: CI (`baza`) pilnuje, że seed odpowiada makiecie. Nie jest testem RLS (T4).
- Terminy szkoleń → `terms = NULL` dla wszystkich 9, bo w makiecie każde szkolenie ma terminy
  domyślne (`TERMINY_DOMYSLNE`), a kontrakt kolumny mówi „NULL ⇒ terminy domyślne”. Wpisanie tych
  samych trzech terminów do bazy rozjechałoby się ze stałą przy jej zmianie.
- Kolejność przypisań → jak `przypisaniaZMakiety` (atrapa w testach widoków): `sort_order_szkolenie`
  = indeks w `teach`, `sort_order_trener` = kolejność trenerów w makiecie wskazujących szkolenie.
- `published_at` → ustawia wyzwalacz `dotknij_updated_at` przy wstawieniu ze statusem `published`
  (czas resetu), bez stałej daty w seedzie.
- Konta testowe → stałe UUID (`…e001`, `…e002`), hasło `bcrypt` przez `extensions.crypt`, wiersz w
  `auth.identities` (provider `email`) i puste napisy w kolumnach tokenów `auth.users`, bo GoTrue nie
  loguje kont z NULL w tych kolumnach. Rejestracja jest wyłączona (`enable_signup = false`), więc
  konta zakłada tylko seed.
- Hasła testowe → `redaktor-lokalnie` i `bez-roli-lokalnie` (≥ 6 znaków, `minimum_password_length`),
  jawne w README z dopiskiem „tylko lokalnie”.
- `.env.local` w README → klucz `publishable_key` z `shctl db status --json` (karta W-04: „klucz
  publishable lokalnego stacku”). Sprawdzone, że lokalne API przyjmuje go do odczytu katalogu i
  logowania.
- Adres lokalny → `http://localhost:8080`: port 8080 ustawia `@lovable.dev/vite-tanstack-config`
  (`server.port`), projekt go nie nadpisuje. Nie sprawdzony uruchomieniem `pnpm dev` (sandbox).
- Przeczytane spoza „Wejścia”: `src/test/atrapa-klienta.ts` (mapowanie makiety na wiersze),
  `src/lib/szkolenia/zrodlo-supabase.ts` i `terminy.ts` (kontrakt `terms`), `node_modules/@lovable.dev/
  vite-tanstack-config/dist/index.js` (port), `docs/07-realizacja/T-7.md` (wzór dowodu przez pgTAP).
